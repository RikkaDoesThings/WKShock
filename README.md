# About
A Pishock integration mod for White Knuckle.\
Currently supported triggers:
* Damage
* Death

The mod uses the [PiShockLibrary](https://github.com/MxPuffin/PiShockLibrary) and some code from [REPOShock](https://github.com/MxPuffin/REPOShock) by [MxPuffin](https://github.com/MxPuffin).
# Configurations
Install the mod then add your credentials in to com.xironix.wkshock.cfg file in the config folder. Configuration in game is currently not implemented.
You can get your Pishock api and username key [here](https://login.pishock.com/account) and the access code [here](https://pishock.com/#/control)
